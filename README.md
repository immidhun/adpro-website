# Ad Pro Advertising website

Static site for https://adproadvertising.in. Edit src/build.py, src/posts.py (blog) and src/site.css. From src/, run `py make_covers.py` when a post is added or its cover text changes, then `py build.py` (outputs src/dist/), and copy src/dist to the repo root. Update LASTMOD in build.py when pages change, and ASSET_V when CSS or JS changes.
Client screenshots work-*.jpg live only on the server.
